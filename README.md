# Как экспортировать данные для графика
*делается для совсем нешарящих*

Данные для построения графика необходимо экспортировать в формате `.csv`
В excel нужно создать новый лист и туда вставить необходимые данные в следующем формате:

| 0   | 0   |
| --- | --- |
| 1   | 5   |
| 2   | -1  |
| 3   | 2   |

Первый столбец - значения X
Второй столбец - значения Y

Далее необходимо перейти по пути Файл $\to$ Экспорт $\to$ Изменить тип файла и выбрать тип файла "CSV (разделитель - запятая) ( \*. csv)"


> [!IMPORTANT] Важно
> График изначально отцентрирован по (0,0) и если значения находятся очень далеко от этой точки, то нужно нажать ПКМ по окну с графиком и нажать "Вписать" и через пару секунд подвигать график
